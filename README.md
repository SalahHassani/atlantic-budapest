# Atlantic Budapest Website

**Your Business. Our Support.**  
Corporate website for **Atlantic Budapest** — business registration, courier onboarding (Wolt & foodora), and ongoing administrative assistance in Budapest, Hungary.

Developed by **Team Atlas**.

## Tech Stack

- **Framework:** React + Vite (JavaScript)
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Forms & Validation:** React Hook Form + Zod

## Project Structure

```text
